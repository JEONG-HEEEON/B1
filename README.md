# 📝 Prompt Manager (나만의 프롬프트 관리 프로그램)

> **GenAI 프롬프트 체계화 & Git 버전 관리 미션 프로젝트** > 흩어져 있던 AI 지시문과 키워드를 한곳에서 체계적으로 관리하고, Python 기초 알고리즘과 Git/GitHub 활용 능력을 다지기 위한 콘솔 기반 프로그램입니다.

---

## 📌 주요 기능

| 기능 | 설명 |
| :--- | :--- |
| **1. 프롬프트 추가** | 제목, 내용, 카테고리를 입력받아 신규 프롬프트를 등록합니다. (빈 값 예외 처리 포함) |
| **2. 프롬프트 목록** | 등록된 전체 프롬프트를 번호, 카테고리, 즐겨찾기 여부(⭐)와 함께 출력합니다. |
| **3. 카테고리별 조회** | 원하는 카테고리를 선택하여 해당 분야의 프롬프트만 필터링하여 확인합니다. |
| **4. 프롬프트 검색** | 키워드를 입력받아 제목 또는 내용에 포함된 프롬프트를 실시간 검색합니다. |
| **5. 프롬프트 상세 보기** | 프롬프트 번호를 선택하여 긴 지시문 전체 내용과 상세 정보를 확인합니다. |
| **6. 즐겨찾기 관리** | 자주 사용하는 프롬프트를 토글(Toggle) 방식으로 즐겨찾기 추가/해제합니다. |
| **7. 즐겨찾기 목록** | ⭐ 즐겨찾기 등록된 프롬프트만 모아서 따로 출력합니다. |

---

## 📂 프롬프트 카테고리
1. **텍스트 생성** (블로그, 이메일, 요약 등)
2. **이미지 생성** (미드저니, DALL-E, 썸네일 등)
3. **영상 생성** (비디오 스크립트, 콘티 등)
4. **페르소나** (전문가 역할 부여 등)
5. **자동화** (노코드 툴 연동, 데이터 처리 등)
6. **기타**

---

## 🛠️ 개발 환경 및 사용 기술

- **Language:** Python 3.10 이상
- **IDE:** Visual Studio Code (VSCode)
- **Version Control:** Git, GitHub
- **Libraries:** Python Standard Libraries (`sys` 전역 라이브러리 사용, 외부 의존성 없음)
